# 闸 D：第一眼

## 方法

三版同题海报（A 现版 / B 标志主导 / C 产品主导），导出 760×1075 的 JPG，交给两位不看上下文的评委盲排。
评委只拿图与「评判标准」，不告诉哪一版是作者自己的。

- `proof/gate-d-poster-A.jpg`：竖皮尺为主轴，标题 / 四要素 / 实景 / 米数标 / 三年 / 产地
- `proof/gate-d-poster-B.jpg`：大号米字格占上半版，其余顺序下排
- `proof/gate-d-poster-C.jpg`：三款米袋并置，产品主导

## 第一轮（2 位评委，独立）

| 评委 | 排名 | 对 A 的批评 |
| --- | --- | --- |
| 评委一 | **A 1 / C 2 / B 3** | 形式即主张（整页是一把竖尺）；但全页无实景图，四要素与正文同字号，300–450 有一条空带 |
| 评委二 | **A 1 / C 2 / B 3** | 会停在 A 上；但「一袋一孔」比主张句大，层级反了；三年行与脚注重复 |

两人独立点名同一件事：**三版都没有产地视觉**（土、棚、人、菜），"一眼看出产地"这条都没过。

## 改法（只改 A）

1. 加一幅双色调实景通栏（菜地 → 改为「双手抱竹篮的刚摘菜」），放在四要素与米数标之间；
2. 主张句字号 58 → 86，压过「一袋一孔」；四要素改为「标签小、数值大」，消费增收一项加红加粗；
3. 删掉与三年行重复的脚注，换成「设计提案 · 未与村集体签署协议」；
4. 竖皮尺加重：外框 6px、主刻度 7px、数字 48px（原来细到三米外看不见）。

## 第二轮（同两位评委）

| 评委 | 排名 | 结论 |
| --- | --- | --- |
| 评委一 | **A 1** | 产地视觉解决；层级不再是平的；放现场能进终评。余下最该修的：图注两行、字号偏小 |
| 评委二 | **A 1** | 能进终评。余下两处：主张句仍不够突出、实景条压得太薄 |

两轮都把 A 排第一，且第二轮两人都判"能进终评"。

## 第三位评委（新眼睛，只看最终 A）

结论：**不能进终评**。理由一条：主视觉是 AI 生成且自标"非实拍"，在没有实拍的前提下，
"产地"这一项缺少证据感——越诚实标注，越暴露证据缺位。

## 结论：条件性通过（分歧留档，不粉饰）

- 支持：两位评委两轮独立盲排，A 均第 1，第二轮均判"能进终评"；两位点到的具体问题（无产地视觉、层级反转、行重复、皮尺过细）已逐条改掉。
- 反对：第三位评委认为「AI 示意图 ≠ 产地证据」，这一条**无法在本机解决**——三兴片在长沙，本机没有实拍。
- 折中：海报已加「数据来源」一行（村情/奥体/收菜时刻/开工数各自标注出处），把证据重心从图转到**可核的数**；图注与说明均写明"AI 生成，非实地照片"。
